          Version1.2.1November 18, 2026

          Employee analytics and lunch-aware blocking

          Adds employee-level website usage reporting and bulk work-hour schedules with a configurable lunch access window.

          • Attribute website usage to employees and show per-website time, visits, and estimated data usage
          • Persist browsing counters across extension service-worker restarts
          • Create bulk schedules that pause blocking during lunch and resume afterward
          • Validate employee-owned analytics inserts and migrate existing usage records to employee IDs

          Admin experience update

          Improves dashboard attention workflows, employee account actions, and login usability.

          • Move the Needs attention panel below the dashboard metric cards
          • Add a Settings option for assignment retention days
          • Add password reset confirmation fields for employee accounts
          • Add an employee actions gear menu with password reset
          • Improve login password visibility controls in light and dark mode
          Version1.1.0November 8, 2026

          Employee and device monitoring update

          • Assign and reassign laptops to employees while retaining assignment history
          • Register and revoke devices with unique device IDs and authorized MAC address records
          • Show laptop registration, online/offline status, and last heartbeat in employee and laptop views
          • View and filter device connection history by employee, laptop, and date
          • Send authenticated device heartbeats through the Chrome/Edge employee extension
          • Support employee-specific or all-employee website blocking schedules
          • Add login light and dark mode and simplify laptop registration fields
