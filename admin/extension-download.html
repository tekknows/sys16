Managed employee browser

Download LOCTIV Extension

Install the LOCTIV extension on an approved company laptop to receive employee access, support tickets, usage reporting, and website blocking policies.

Download extension v1.2.7 Admin login

Install in Chrome or Edge

  1. Download and extract the ZIP file.
  2. Open chrome://extensions or edge://extensions.
  3. Enable Developer mode.
  4. Select Load unpacked and choose the extracted extension folder.
  5. Open LOCTIV and sign in with the employee account.

Important: Keep LOCTIV enabled and signed in so admin website blocking policies can be synchronized and enforced.
